# Reectructurar Datos: Pivote

**DataFrame** `weather`

```output
+-------------+--------+
| Column Name | Type   |
+-------------+--------+
| city        | object |
| month       | object |
| temperature | int    |
+-------------+--------+
```

Escribe una solución para **pivotear** los datos de modo que cada fila represente las temperaturas de un mes específico, y cada ciudad sea una columna separada.

## Ejemplo

::::columns
:::col
**Input:**
```output
+--------------+----------+-------------+
| city         | month    | temperature |
+--------------+----------+-------------+
| Jacksonville | January  | 13          |
| Jacksonville | February | 23          |
| Jacksonville | March    | 38          |
| Jacksonville | April    | 5           |
| Jacksonville | May      | 34          |
| ElPaso       | January  | 20          |
| ElPaso       | February | 6           |
| ElPaso       | March    | 26          |
| ElPaso       | April    | 2           |
| ElPaso       | May      | 43          |
+--------------+----------+-------------+
```
:::
:::col
**Output:**
```output
+----------+--------+--------------+
| month    | ElPaso | Jacksonville |
+----------+--------+--------------+
| April    | 2      | 5            |
| February | 6      | 23           |
| January  | 20     | 13           |
| March    | 26     | 38           |
| May      | 43     | 34           |
+----------+--------+--------------+

Explicación:
La tabla se pivota, cada columna 
representa una ciudad, y cada fila
representa un mes específico.
```
:::
::::



## Soluciones

:::solution[Python]{icon="Python"}
```python
import pandas as pd

def pivotTable(weather: pd.DataFrame) -> pd.DataFrame:
    return weather.pivot(
        index='month',
        columns='city',
        values='temperature'
    )
```
:::
