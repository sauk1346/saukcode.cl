Escribe una solución para concatenar estos dos DataFrames **verticalmente** en un solo DataFrame.

## Ejemplo

**Input**

```output
df1                                df2
+------------+---------+-----+     +------------+------+-----+
| student_id | name    | age |     | student_id | name | age |
+------------+---------+-----+     +------------+------+-----+
| 1          | Mason   | 8   |     | 5          | Leo  | 7   |
| 2          | Ava     | 6   |     | 6          | Alex | 7   |
| 3          | Taylor  | 15  |     +------------+------+-----+
| 4          | Georgia | 17  |
+------------+---------+-----+
```

**Output**

```output
+------------+---------+-----+
| student_id | name    | age |
+------------+---------+-----+
| 1          | Mason   | 8   |
| 2          | Ava     | 6   |
| 3          | Taylor  | 15  |
| 4          | Georgia | 17  |
| 5          | Leo     | 7   |
| 6          | Alex    | 7   |
+------------+---------+-----+

Explicación:
Los dos DataFrames se apilan verticalmente, y sus filas se combinan.
```


## Soluciones

:::solution[Python]{icon="Python"}
```python
import pandas as pd

def concatenateTables(df1: pd.DataFrame, df2: pd.DataFrame) -> pd.DataFrame:
    return pd.concat([df1,df2])
```
:::
