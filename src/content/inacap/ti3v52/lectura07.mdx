# Configuración y verificación de enrutamiento estático redes de datos

## 1. El rol del router y conectividad

La capacidad de comunicar dispositivos que pertenecen a redes distintias

- Separa dominios de broadcast (evita que el tráfico inunde toda la red)
- Actúa como punto de control para seguridad y políticas de tráfico
- Realiza la interconexión de subredes dispares

## 3. Precisión Manual: ¿por qué elegir rutas estáticas?

Una ruta estática es un camino configurado manualmente hacia una red remota. No se ajusta automáticamente ante fallas, pero ofrece un control total.

- **Estabilidad de Topología:** Ideal cuando la red cambia poco
- **Simplicidad Operacional:** Para redes pequeñas (*stub networks*), donde un protocolo dinámico sería excesivo
- **Control del flujo:** Cuando el ingeniero necesita forzar el tráfico por un camino específico, por seguridad o ancho de banda

<Callout type="warning" title="Desventaja crítica">
Mantenimiento administrativo alto. Si un enlace falla, la ruta estática permanece en la tabla hasta ser removida manualmente.
</Callout>
