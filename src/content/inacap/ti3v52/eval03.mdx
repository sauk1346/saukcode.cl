2. Realice configuración de protocolo de enrutamiento OSPFv2 en router SUNOMBRE:
    - ID de proceso 1000+X (ej: si X=15, ID=1015)
    - El valor de X será entregado por su docente
    - ID de router: 110.110.110.110
    - Declare o publique las redes directamente conectadas con su correspondiente WildCardMask y en área 0 backbone
    - No enviar información de enrutamiento por interfaces que no sea necesario o inseguro

<Solution title="Solución Pregunta 02">

<TerminalOutput 
caption="Configuración enrutamiento OSPFv2 en router SUNOMBRE"
withBg>
{`ANTONIO>enable
ANTONIO#configure terminal

# El valor de X (X=21) fue entregado por el docente, ID de proceso = 1000+X = 1021
ANTONIO(config)#router ospf 1021

# ID de router: 110.110.110.110
ANTONIO(config-router)#router-id 110.110.110.110

# Declara y publica las redes directamente conectadas con su WildCardMask en área 0 backbone
ANTONIO(config-router)#network 172.31.0.0 0.0.7.255 area 0
ANTONIO(config-router)#network 172.31.9.0 0.0.1.255 area 0
ANTONIO(config-router)#network 172.31.10.128 0.0.0.3 area 0

# No envía información de enrutamiento por interfaces que no sean necesarias o inseguras
ANTONIO(config-router)#passive-interface default
ANTONIO(config-router)#no passive-interface s0/0/0`}
</TerminalOutput>


</Solution>

4. Realice configuración de protocolo de enrutamiento OSPFv2 en router SEGUNDOAPELLIDO:
    - Agregue una Interface Loopback 190 con IP=190.190.190.1 M=255.255.255.255
    - Agregar ruta estática por defecto que ocupe la interface loopback como salida
    - ID de proceso: 3000+X (ej: si X=15, ID=1015)
    - El valor de X será entregado por su docente
    - ID del router: 30.30.30.30
    - Habilite cada interfaz del router para ospf en área backbone
    - No enviar información de enrutamiento por interfaces que no sea necesario o inseguro
    - Redistribuya la ruta por defecto dentro de ospf

<Solution title="Solución Pregunta 04">
<TerminalOutput 
caption="Configuración enrutamiento OSPFv2 en router SEGUNDOAPELLIDO"
withBg
>
{`CAQUEO>enable
CAQUEO#configure terminal

# Agrega una Interface Loopback 190 con IP=190.190.190.1 M=255.255.255.255
CAQUEO(config)#interface loopback 190
CAQUEO(config-if)#ip address 190.190.190.1 255.255.255.255

# Agrega ruta estática por defecto que ocupa la interface loopback como salida
CAQUEO(config-if)#ip route 0.0.0.0 0.0.0.0 loopback 190

# El valor de X (X=21) fue entregado por el docente, ID de proceso = 3000+X = 3021
CAQUEO(config-if)#router ospf 3021

# ID de router: 30.30.30.30
CAQUEO(config-router)#router-id 30.30.30.30
CAQUEO(config-router)#exit

# Habilita cada interfaz del router para ospf en área backbone
CAQUEO(config)#interface g0/0
CAQUEO(config-if)#ip ospf 3021 area 0
CAQUEO(config-if)#interface g0/1
CAQUEO(config-if)#ip ospf 3021 area 0
CAQUEO(config-if)#interface s0/0/1
CAQUEO(config-if)#ip ospf 3021 area 0
CAQUEO(config-if)#exit

# No envía información de enrutamiento por interfaces que no sean necesarias o inseguras
CAQUEO(config)#router ospf 3021
CAQUEO(config-router)#passive-interface default
CAQUEO(config-router)#no passive-interface s0/0/1

# Redistribuye la ruta por defecto dentro de ospf
CAQUEO(config-router)#default-information originate`}
</TerminalOutput>

</Solution>
