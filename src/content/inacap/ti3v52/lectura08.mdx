- Los routers OSPF envían paquetes 'Hello' periódicoa para descubrir vecinos y mantener la relación activa
- Para que 2 routers establezcan una adyacencia completa, deben coincidir en:
    - Misma subred y máscara
    - Mismo ID de área
    - Temporizadores (Hello/Dead intervals) idénticos
    - Autenticación compatible (si está configurada)

## 4. Arquitectura de Área Única (Backbone)

- **El Núcleo (Área 0):** todas la redes OSPF deben tener un área backbone (Área 0). En diseño pequeños o iniciales, toda la red reside dentro de esta única área
- **Propósito:** el diseño de área única simplifica la comprensión del intercambio del *Link-State Advertisements* (LSAs), y es el paso previo antes de escalar a diseño multiárea.
- **Eficiencia:** la división por áreas futuras permitirá segmentar el tráfico de actualización, pero el dominio del Área 0 es crítico para la estabilidad
