## 2. Estadística descriptiva

### Medidas de posición

Las medidas de posición dividen los datos ordenados en partes con la misma cantidad de observaciones. `summary()` entrega el mínimo, los tres cuartiles, la media y el máximo.

```r
summary(mpg$cty)   # rendimiento en millas por galón en ciudad
```

```terminal
   Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
   9.00   14.00   17.00   16.86   19.00   35.00
```

`quantile()` calcula los percentiles que se le pidan. Con 0.25, 0.5 y 0.75 entrega los cuartiles: un 25 % de los autos rinde 14 millas por galón o menos, la mitad rinde 17 o menos y un 75 % rinde 19 o menos.

```r
quantile(mpg$cty, probs = c(0.25, 0.5, 0.75))
```

```terminal
25% 50% 75% 
 14  17  19
```

### Medidas de tendencia central

Indican el valor en torno al cual se agrupan los datos.

```r
mean(mpg$cty)
```

```terminal
[1] 16.85897
```

```r
median(mpg$cty)
```

```terminal
[1] 17
```

### Medidas de dispersión

Indican qué tan separados están los datos entre sí. La **desviación estándar** es la raíz cuadrada de la varianza; `sd()` la calcula directamente.

```r
sqrt(var(mpg$cty))   # desviación estándar
```

```terminal
[1] 4.255946
```

```r
sd(mpg$cty)   # desviación estándar
```

```terminal
[1] 4.255946
```

```r
sd(mpg$hwy)   # millas por galón en carretera
```

```terminal
[1] 5.954643
```

### Coeficiente de variación

La desviación estándar está en la misma unidad que los datos, así que no sirve para comparar variables de escalas distintas. El **coeficiente de variación** mide la dispersión relativa: divide la desviación estándar por la media. Suele expresarse como porcentaje y permite comparar la variabilidad de conjuntos de datos con distintas escalas o unidades.

```r
sd(mpg$cty) / mean(mpg$cty)
sd(mpg$hwy) / mean(mpg$hwy)
```

```terminal
[1] 0.2524439
[1] 0.2540358
```

El rendimiento en carretera tiene mayor desviación estándar que el de ciudad (5,95 contra 4,26), pero también una media más alta. En términos relativos, ambos varían lo mismo: cerca de un 25 %.

## 3. Correlación de variables

La **correlación** busca cuantificar el nivel de asociación que existe entre dos variables. El coeficiente más usado es el de **Pearson**, que toma valores entre −1 y 1:

- **1:** correlación positiva o directamente proporcional. La nube de puntos sigue una recta de pendiente positiva.
- **−1:** correlación negativa o inversamente proporcional.
- **0:** no hay relación lineal.

### Seleccionar las variables

`dplyr` es una librería para manipular tablas. Su función `select()` se queda con las columnas indicadas.

```r
library(dplyr)   # librería de manipulación de tablas
datos <- select(mpg, displ, hwy)   # hwy: millas por galón; displ: cilindrada
datos
```

Antes de calcular, conviene mirar. `geom_point()` dibuja la nube de puntos y `geom_smooth()` le agrega una línea de tendencia; con `method = "lm"` esa línea es una recta.

```r
ggplot(datos) + aes(x = displ, y = hwy) + geom_point() + geom_smooth(method = "lm")
```

### Calcular la correlación

`cor()` sobre una tabla entrega la **matriz de correlaciones**: cada casilla es la correlación entre la variable de su fila y la de su columna. La diagonal vale 1 porque cada variable se correlaciona perfectamente consigo misma.

```r
cor(datos)   # Pearson
```

```terminal
         displ      hwy
displ  1.00000 -0.76602
hwy   -0.76602  1.00000
```

Una correlación de −0,77 confirma lo que mostraba el gráfico: una relación inversa y fuerte.

Con `method` se elige otro coeficiente. **Spearman** y **Kendall** no miden si los puntos forman una recta, sino si una variable crece (o decrece) siempre que la otra lo hace, aunque sea en curva.

```r
cor(datos, method = "spearman")
```

```terminal
           displ        hwy
displ  1.0000000 -0.8266576
hwy   -0.8266576  1.0000000
```

```r
cor(datos, method = "kendall")
```

```terminal
           displ        hwy
displ  1.0000000 -0.6536974
hwy   -0.6536974  1.0000000
```

### Una relación que no es lineal

```r
install.packages("tidyverse")
install.packages("corrplot")
```

Para ver la diferencia entre los coeficientes se fabrican datos con una relación conocida. `rnorm()` genera números aleatorios con distribución normal (gaussiana). `x` son 100 de esos números, `e` es un ruido aleatorio y `y` depende de `x` al cubo: la relación existe, pero es una curva, no una recta.

```r
x <- rnorm(100)
e <- rnorm(100, sd = 1)
y <- 1 + 3 * x^3 + e
A <- data.frame(x = x, y = y)
A
```
