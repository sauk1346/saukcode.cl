### Graficar una matriz

`matplot()` dibuja una línea por cada **columna** de la matriz. Por eso se le entrega la matriz traspuesta: así cada línea es un jugador y el eje horizontal recorre las temporadas.

- `type = "b"`: gráfico con líneas y puntos.
- `pch = 15:20`: un tipo de punto distinto para cada línea.
- `col = c(1:4)`: un color distinto para cada línea.

```r
matplot(t(matrizGoles), type = "b", pch = 15:20, col = c(1:4))
```

Un ejemplo aparte, con datos de prueba, muestra cómo se agrega. `plot()` dibuja los puntos y `legend()` añade la leyenda sobre el gráfico ya hecho: se indica su posición (`"topright"`, arriba a la derecha), los textos y los mismos símbolos y colores del gráfico.

```r
legend("topright", inset = 0.01, legend = jugador, pch = 15:18, col = c(1:4))
```

### Una función propia para graficar

Con `function()` se define una función propia: entre paréntesis van sus argumentos y entre llaves el código que ejecuta. Esta junta los dos pasos anteriores, graficar y agregar la leyenda, y permite elegir qué jugadores y qué temporadas mostrar.

- `datos`: matriz de datos a graficar.
- `legendaDatos`: vector con los nombres de los jugadores.
- `filas`: posiciones de las filas (jugadores) a graficar.
- `columnas`: posiciones de las columnas (temporadas) a graficar.

```r
generarGraficoEjemplo <- function(datos, legendaDatos, filas, columnas) {
  # Graficar los datos seleccionados
  matplot(t(datos[c(filas), c(columnas)]), type = "b", pch = 15:20, col = c(1:4))
  # Añadir leyenda
  legend("topright", inset = 0.01, legend = legendaDatos, pch = 15:20, col = c(1:4))
}
```

La versión final cambia dos cosas: la leyenda va arriba a la izquierda (`"topleft"`) y solo incluye a los jugadores seleccionados (`legendaDatos[filas]`). Después se llama a la función con todos los jugadores y todas las temporadas.

```r
generarGraficoEjemplo <- function(datos, legendaDatos, filas, columnas) {
  # Graficar los datos seleccionados
  matplot(t(datos[c(filas), c(columnas)]), type = "b", pch = 15:20, col = c(1:4))
  # Añadir leyenda
  legend("topleft", inset = 0.01, legend = legendaDatos[filas], pch = 15:20, col = c(1:4))
}

# Gráfico con todos los jugadores y todas las temporadas
generarGraficoEjemplo(matrizGoles, jugador, 1:4, 1:4)
```


### Cruzar las tablas con `merge()`

Las dos tablas hablan de los mismos países, pero cada una tiene datos que la otra no. `merge()` las une en una sola, emparejando las filas que comparten el mismo valor en una columna clave. Aquí la clave es el código del país, que se llama distinto en cada tabla: `by.x` es su nombre en la primera y `by.y` en la segunda.

```r
dataFrame3 <- merge(
  valores,
  dataFrameValores2,
  by.x = "Codigo.Pais",
  by.y = "Codigo"
)

head(dataFrame3)
```

### Graficar con `ggplot2`

`ggplot2` es una librería para hacer gráficos. No viene con R: se instala una vez con `install.packages()` y se carga en cada sesión con `library()`.

```r
install.packages("ggplot2")
```

Un gráfico de `ggplot2` se arma por partes que se suman con `+`:

- `ggplot(data = ...)` indica la tabla de datos.
- `aes()` asocia columnas a propiedades del gráfico: aquí, el eje horizontal (`x`), el eje vertical (`y`) y el color.
- `geom_point()` dibuja un punto por cada fila, es decir, un gráfico de dispersión.

```r
library(ggplot2)

ggplot(data = dataFrame3, aes(x = CantPersonas.Internet, y = Tasa.Natalidad, size = 2, color = Region)) +
  geom_point()
```
