## I. Estadísticos descriptivos

- **Medidas de posición:** valores que permiten dividir la muestra en conjuntos con aproximadamente la misma cantidad de individuos.
- **Medidas de tendencia central:** valores en torno a los cuales tienden a agruparse los datos de la muestra.
- **Medidas de dispersión:** cuantifican el nivel de heterogeneidad de una variable numérica.

En R hay funciones para todas ellas:

:::table{#tabla01 caption="Funciones para estadísticos descriptivos" layout="mixed" widths="160px,auto"}
| Función | Qué entrega |
| --- | --- |
| `summary()` | Por defecto, estadísticos de posición (cuartiles), mínimo, máximo y media |
| `quantile()` | Uno o varios percentiles de interés |
| `mean()` | La media de un vector numérico |
| `median()` | La mediana de un vector numérico |
| `sd()` | La desviación estándar muestral |
| `var()` | La varianza muestral |
:::

## II. Correlación de variables

Las medidas de correlación buscan cuantificar el nivel de asociación que existe entre dos variables. Uno de los coeficientes más populares para medir la dependencia lineal entre dos variables es el coeficiente de correlación de **Pearson**.

Matemáticamente, el coeficiente de correlación de Pearson entre dos variables aleatorias $X$ e $Y$ se define como:

$$
\rho = \dfrac{\mathbb{E}[(X-\mu_X)(Y-\mu_Y)]}{\sigma_X \, \sigma_Y}
$$

Donde $\mu_X$ y $\mu_Y$ son las medias y $\sigma_X$ y $\sigma_Y$ las desviaciones estándar de cada variable. Este coeficiente varía entre −1 y 1, y alcanza esos valores extremos cuando $X$ e $Y$ forman una recta.

### Una relación no lineal

Se generan datos donde `y` depende de `x` al cubo, más un ruido aleatorio `e`.

```r
x <- rnorm(100)
e <- rnorm(100, sd = 1)

y <- 1 + 3 * x^3 + e

A <- data.frame(x = x, y = y)

library(ggplot2)
ggplot(A) + aes(x, y) + geom_point()
```

<img
	src="/inacap/ti3v61/images/clase10c-04.jpg"
	alt="El mismo gráfico de dispersión hecho con la función plot"
	style={{ display: 'block', margin: '0 auto', width: '70%', background: '#fff' }}

```r

cor(x, y, method = "spearman")
```

```terminal
[1] 0.778055

```

Pearson, que mide qué tan cerca están los puntos de una recta, da 0,78. Spearman, que solo mide si `y` crece cuando `x` crece, da 0,88: capta mejor esta relación porque es creciente pero curva. Como los datos son aleatorios, los valores cambian en cada ejecución.

:::solution[Qué se observa]
**P1.** `cor()` entrega la correlación de cada par de variables. El rendimiento (`mpg`) tiene una correlación negativa fuerte con la cilindrada (−0,85), el peso (−0,87) y la potencia (−0,78): los autos más grandes, pesados y potentes rinden menos. La cilindrada y el peso se mueven juntos (0,89). En cambio, `drat` y `qsec` casi no se relacionan entre sí (0,09).

**P2.** Con Spearman los signos no cambian, pero varias correlaciones se hacen más fuertes: la de `mpg` con `disp` pasa de −0,85 a −0,91 y la de `mpg` con `hp` de −0,78 a −0,89. Eso indica que la relación entre esas variables es consistente pero no del todo recta, como se ve en las curvas de la matriz de gráficos.
:::

El argumento `method` acepta siete valores: `"circle"` (círculos), `"square"` (cuadrados), `"ellipse"` (elipses), `"number"` (el valor numérico), `"shade"` (sombreado), `"color"` (casillas de color) y `"pie"` (gráficos de torta).
