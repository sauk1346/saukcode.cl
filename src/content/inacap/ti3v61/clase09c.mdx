# Condicionales y ciclos

**Material:** [Cuaderno original (.ipynb)](/inacap/ti3v61/docs/clase09c.ipynb)

Todo lenguaje de programación necesita expresiones que permitan controlar el flujo de un proceso: decidir qué código se ejecuta y cuántas veces. En R esas expresiones son la sentencia `if else` y los ciclos `repeat`, `while` y `for`.

En los ejemplos se usa la tabla `precipitaciones`, que se construye y se guarda al final de la [vista general de R (continuación)](/inacap/ti3v61/clase09b).

:::callout[Atajos de teclado en RStudio]{type="tip"}
En RStudio, estos atajos ayudan a ordenar el código:

- `Ctrl + Shift + R`: inserta una sección.
- `Ctrl + Shift + C`: comenta o descomenta las líneas seleccionadas.
- `Ctrl + Shift + A`: da formato al código seleccionado.
:::

## 1. Control de flujo

### Sentencia `if else`

La sintaxis es bastante estándar. Las llaves son opcionales cuando la sentencia se escribe en una sola línea.

```r
if (condicion_logica) {
  # código que se ejecuta si la condición es verdadera
} else {
  # código que se ejecuta si es falsa
}
```

Una sentencia condicional que compara una variable con un valor:

```r
x <- 10

if (x > 6) {
  print("Sí, x es mayor a 6")
} else {
  print("Ups")
}
```

```terminal
[1] "Sí, x es mayor a 6"
```

### `if` evalúa una sola condición

¿Y si se compara un vector con una variable?

```r
y <- c(1, 4, 20)

if (x > y) {
  print("Sí, x es mayor a 6")
} else {
  print("Ups")
}
```

```terminal
Error in if (x > y) {: the condition has length > 1
```

`x > y` devuelve tres valores (`TRUE`, `TRUE`, `FALSE`), pero `if` necesita una sola respuesta para decidir, y por eso da error.

:::callout[Cambio entre versiones de R]{type="warning"}
Hasta la versión 4.1, R no daba error en este caso: evaluaba solo el primer valor del vector y mostraba una advertencia. Desde R 4.2 es un error.
:::

### La función `ifelse()`

Para evaluar varios valores a la vez se usa la función `ifelse()`, que es vectorizada. Recibe una condición y dos alternativas: donde la condición es `TRUE` toma el valor de la primera, y donde es `FALSE`, el de la segunda.

```r
a <- c("x", "y", "z", "w", "q")
b <- c(1, 2, 3, 4, 5)
ifelse(c(TRUE, FALSE, TRUE, FALSE, TRUE), a, b)
```

```terminal
[1] "x" "2" "z" "4" "q"
```

El resultado es todo texto porque un vector solo guarda un tipo de dato: al mezclar letras y números, estos se convierten en texto.

```r
a <- c(2, 5, 1, -2, 10)
b <- c(1, 2, 3, 4, 5)
ifelse(a >= b, "Si se cumplió", "no se cumplió")
```

```terminal
[1] "Si se cumplió" "Si se cumplió" "no se cumplió" "no se cumplió"
[5] "Si se cumplió"
```

## 2. Ciclos

En R existen tres tipos de ciclos (*loops*): `repeat`, `while` y `for`.

### 2.1 `repeat`

`repeat` simplemente repite una expresión. Para detener el ciclo se usa la instrucción `break`. Su sintaxis es:

```r
repeat {
  # expresión
}
```

:::callout[Ciclo infinito]{type="warning"}
Sin una condición de salida, el ciclo no termina nunca: imprime «lala» indefinidamente hasta que se interrumpe la ejecución a mano.
:::

```r
repeat {
  print("lala")
}
```

Con `break`, el ciclo se detiene en la primera vuelta.

```r
repeat {
  print("lala")
  break
}
```

```terminal
[1] "lala"
```

Usando `repeat` y la sentencia `if`, se imprime la palabra «lala» 25 veces: un contador aumenta en cada vuelta y el ciclo se corta cuando pasa de 25.

```r
cont <- 1
repeat {
  print("lala")
  cont <- cont + 1

  if (cont > 25) {
    break
  }
}
```

```terminal
[1] "lala"
[1] "lala"
[1] "lala"
# ... 25 líneas iguales en total
```

En R, muchas veces un ciclo se puede reemplazar por una función vectorizada. `rep()` entrega las 25 repeticiones en una sola instrucción, como un vector:

```r
rep("lala", 25)
```

```terminal
 [1] "lala" "lala" "lala" "lala" "lala" "lala" "lala" "lala" "lala" "lala"
[11] "lala" "lala" "lala" "lala" "lala" "lala" "lala" "lala" "lala" "lala"
[21] "lala" "lala" "lala" "lala" "lala"
```

### 2.2 `while`

`while` funciona igual que en la mayoría de los lenguajes: repite la expresión mientras la condición sea verdadera.

```r
while (condicion) {
  # expresión
}
```

El mismo ejemplo, imprimir «lala» 25 veces:

```r
cont <- 1
while (cont <= 25) {
  print("lala")
  cont <- cont + 1
}
```

```terminal
[1] "lala"
[1] "lala"
[1] "lala"
# ... 25 líneas iguales en total
```

### 2.3 `for`

Uno de los ciclos más usados es `for`, que ejecuta una expresión recorriendo los elementos de un arreglo. Ese arreglo puede ser un vector, no necesariamente numérico, o incluso una lista.

```r
for (variable in vector_o_lista) {
  # expresión
}

for (x in c(1, 5, 7, 10)) {
  print(x * 10)
}
```

```terminal
[1] 10
[1] 50
[1] 70
[1] 100
```

Aquí también hay una alternativa vectorizada, que entrega el mismo resultado como un solo vector:

```r
c(1, 5, 7, 10) * 10
```

```terminal
[1]  10  50  70 100
```

Con `for` se puede repetir la impresión de «lala», mostrando además el número de cada vuelta.

```r
for (i in 1:25) {
  print("lala"); print(i)
}
```

```terminal
[1] "lala"
[1] 1
[1] "lala"
[1] 2
[1] "lala"
[1] 3
# ... y así hasta el 25
```

También se puede recorrer un vector que no es numérico. `paste()` une textos, separándolos con un espacio.

```r
palabras <- c("juan", "pedro", "horacio", "miguel")

for (p in palabras) {
  print(paste("hola: ", p))
}
```

```terminal
[1] "hola:  juan"
[1] "hola:  pedro"
[1] "hola:  horacio"
[1] "hola:  miguel"
```

Aparecen dos espacios porque `"hola: "` ya termina en uno y `paste()` agrega otro.

```r
paste("hola: ", "miguel")
```

```terminal
[1] "hola:  miguel"
```

Incluso se pueden recorrer las columnas de un *data frame*, que es una lista de columnas. Aquí se resume cada columna de `precipit`.

```r
for (c in precipit) {
  print(summary(c))
}
```

Salen cinco resúmenes, uno por columna y en el mismo orden: `Dia_semana`, `Temperatura`, `Llueve`, `Estacion` y `temp2`. El primero es un conteo por día porque en este archivo esa columna está guardada como factor. El último es igual al tercero, lo que confirma que `temp2` reproduce a `Llueve`.

De manera más general, se pueden recorrer los elementos de una lista, aunque sean de tipos distintos.

```r
for (l in list(1, c("A", "b"), data.frame(x = c(1, 2)))) {
  print(l)
}
```

```terminal
[1] 1
[1] "A" "b"
  x
1 1
2 2
```
